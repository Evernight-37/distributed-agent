Agent Harness 新手教程

按五步完成第一次登录、创建项目，并把自己的一台电脑接入 agent 群。共享面板管项目协作，本机控制台管你的电脑。

工作台账户和模型登录是两件事

这里填写 Harness 自己的用户名和密码，不能拿 OpenAI 或 GitHub 账户直接登录工作台。密码没有长度限制，也可以留空。本机控制台没有这个登录表单。

第一次使用：逐步操作

第 1 步：登录共享面板

打开共享服务给你的网址。只有你是第一个使用这套服务的人时，页面会显示“创建账户”；之后显示“登录”。项目成员没有账户时，点击“凭邀请注册”，输入群主生成的一次性邀请代码。

首次账户是这套共享服务的初始账户。它不等于 OpenAI 账户，也不会自动登录 Codex。

第 2 步：创建项目并邀请伙伴

登录后，在左侧“项目”旁点击“＋ 新建”，填写项目名称。打开项目的“成员与设置”页，群主可以点击“生成邀请”，把邀请代码发给伙伴。伙伴在登录页点击“凭邀请注册”，输入代码后就能加入。

项目里的消息、任务和私聊都归属于这个工作群。人类成员可以审计全部消息；agent 只会收到群聊和发给自己的私聊。

第 3 步：配对你自己的电脑

在项目的“成员与设置”页点击“配对我的机器”，输入一个机器名称。页面会生成一个十分钟有效、只能使用一次的配对代码。

把下面命令中的网址、代码和目录换成页面显示的值，在目标电脑的 PowerShell 运行：

python pull_worker.py pair --server https://your-service.example --pair-code CODE --root D:/AgentHarness/my-node

配对成功后，保持执行端运行：

python pull_worker.py loop --config D:/AgentHarness/my-node/pull-config.json

这是目标电脑主动连接共享服务；共享服务不会 SSH 登录或远程执行这台电脑。不同电脑上的 127.0.0.1 是各自本机，不能拿实验室电脑的地址在你的电脑浏览器里打开本机控制台。

第 4 步：打开本机控制台，明确授权

在同一台电脑另开 PowerShell：

python local_panel.py --config D:/AgentHarness/my-node/pull-config.json

然后打开 http://127.0.0.1:8787。依次完成：

  • 展开“注册工作目录 / 固定命令模板”，登记一个明确的本机项目目录。
  • 在“接入项目”选择共享项目和本机执行项目。
  • 填写模型，例如 gpt-5.6-sol；选择思考强度，例如 medium。
  • 勾选“启用此 agent”和“讨论”。默认只讨论，不修改工作区。
  • 只有你明确需要时，再勾选“检查”或“修改工作区”。修改工作区必须使用专属 linked Git worktree。
  • 点“保存本机设置”，再回共享面板查看新 agent。

第 5 步：设置管理员并发第一条消息

回到共享面板的“成员与设置”，群主点击“设置管理员”，选择一个 agent。管理员负责组织讨论、分解任务和向其他 agent 派发工作；人始终可以看到项目中的消息。

切回项目“群聊”，在输入框写下目标、约束和验收方式，例如：“请先讨论实验方案，暂不修改文件；给出分工和需要我决定的问题。” 点击“发送”即可。

我们这两台电脑怎么填地址？

5090 浏览器打开 http://127.0.0.1:8765。5090 执行端的 --server 也是这个地址；4090 执行端的 --server 使用 http://127.0.0.1:18876（现有受保护转发）。18876 只用于设备 API，不能当作共享面板浏览器地址。

本机设置都是 8787：在 5090 打开它，就设置 5090；通过 Parsec 到 4090 打开它，才设置 4090。正式设备尚需主人配对并启用。

两个面板，一条协作通道

共享面板：项目群主视角

项目群聊任务成员与设置

能做：创建项目、邀请成员、设置管理员、发送消息、派发任务。

不能做：替你选择某台电脑的模型、目录，或绕过本机批准执行命令。

本机控制台：机器主人视角

本机设置模型工作目录命令批准

能做：决定这台电脑接入哪些项目、用什么模型和思考强度、允许哪些阶段。

只在这台电脑的 127.0.0.1 上打开。

共享面板项目消息 / 任务请求主动拉取本机执行端本机设置与批准结果回传群聊可见

常见问题

我换网络或换电脑怎么办？
换网络不需要重新配对，只需仍能连接原服务地址。换成另一台电脑，才需要为那台电脑配对并选择目录和权限。不要把不同电脑的 localhost 混用。

需要一直开着什么？
共享面板要在线，目标电脑上的 pull_worker.py loop 要运行。本机控制台只在修改设置或批准作业时打开即可。空闲时 worker 只查询队列，不调用模型。

为什么 agent 没有马上插话？
它会在当前轮次结束后处理新消息，不提供生成中的即时打断。后台长任务由独立进程运行，不会一直占住讨论会话。

共享面板部署在哪？
你可以自己托管一套服务，也可以让团队成员托管。伙伴加入同一套服务的项目即可协作；服务之间目前不会自动同步。

安全提示

不要把 pull-config.json、设备令牌、Codex 认证文件或运行日志提交到 Git。共享服务是消息路由和数据库保管者，能看到它保存的消息；本机设置负责限制模型、目录、阶段和命令模板。

正式部署给多人使用时，请用 HTTPS 共享网址。实验室远程电脑上的浏览器地址 127.0.0.1:8787 只属于那台电脑本身。

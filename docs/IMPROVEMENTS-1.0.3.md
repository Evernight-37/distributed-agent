# Agent Harness 1.0.3

群聊 Agent 现在可以在配置的本机项目目录中使用只读命令，检查代码、已有日志和进程状态。修复此前讨论任务同时禁用了命令工具，导致服务器在线但 Agent 无法查看项目的问题。

人类明确要求修改代码或运行实验时，群管理员可以创建范围明确的 implement 任务，由执行端在项目目录中处理。普通的状态询问仍保持只读。长时间实验应使用机器所有者批准的执行模板；Agent 不会在一轮对话中持续等待训练结束。

修复管理员给自己分派任务后，结果进入自发私聊、群成员看不到回复的问题。给其他 Agent 的私下分工仍遵守原有会话权限。

本次更新需要升级托管端和接收端，并重启后台服务。账户、项目、消息和服务器项目文件保留。附件功能与 1.0.2 相同，附件暂不自动作为模型的文件或图片输入。

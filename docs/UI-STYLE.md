# Foolship 桌面界面指南

新增桌面功能时，沿用现有页面的导航、文字层级、按钮、表单与状态样式。设计背景和前后对照见 [界面调研与审查](UI-REVIEW.md)。

## 布局与视觉

- 方向和状态放在稳定的位置。项目页左侧切换会话，中间看消息，右侧检查任务和项目状态。窗口空间不足时，优先保留当前会话、输入与发送，详情保持可达。
- 沿用 `assets/web/styles/desktop.css` 的背景、文字、边线与交互颜色。正文以 14 像素为基准，时间和辅助信息使用 12–13 像素，页面标题为 22–26 像素。状态用文字说明，颜色辅助区分。
- 每个交互区域突出一个主要动作。审批、确认和重试靠近对应的任务、状态或对象。破坏性操作写清对象和后果。
- 使用已有表单和对话框组件。保留标签、键盘焦点与清楚的禁用反馈。长文本用多行输入，运行细节按需展开。
- 保留会影响操作的说明，例如权限范围、失败原因和操作后果。按钮已经说明动作时可以删掉重复提示。

## 中英文文案

- 新增界面文案同时提供简体中文和英文。页面脚本用 `t(chinese, english)`，静态页面外壳用 `data-en`，静态标题和无障碍标签用 `data-en-title` 和 `data-en-label`。日期用 `interfaceLocale()`。
- 先确认文字来源。界面生成的状态、标签和反馈随语言切换。项目、成员、Agent 的名字，以及聊天、任务描述和原始日志沿用来源文本。权限、协议字段和存储值保持稳定。
- 使用完整句子翻译带变量的文案。让译文有空间自然换行，避免固定宽度截断。需要中英混排时，语言选项以本身名称呈现。
- 检查两种语言、正常及窄窗口、较长标签，以及键盘导航、弹窗关闭后焦点与切换语言后的重启。

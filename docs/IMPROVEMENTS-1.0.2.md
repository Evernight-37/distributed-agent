# Agent Harness 1.0.2

## 群聊文件与图片

Mac 和 Windows 新增“添加文件 / 图片”，支持选择、拖入文件，以及在消息输入框粘贴截图。上传完成后点击发送，可以只发附件，也可以加文字。图片消息提供“预览图片”，文件通过“下载”选择保存位置。

单文件最多 5 MB，每条消息最多 5 个附件，每个项目附件试用容量为 512 MB。附件保存在协作服务的数据库，备份团队数据库时一并备份；未发送的暂存附件在 24 小时后、下一次上传时清理。

附件随消息的会话权限控制。私聊文件不会对其他项目成员开放，退出项目后不能继续下载。HTML、SVG 等文件只作为文件下载，不能内嵌执行。上传失败可重试，发送重试不会重复创建消息。

客户端与托管端都需升级至 1.0.2 并重启后台服务。旧托管端仍可发送文字，附件按钮会提示升级。

本版先提供成员之间收发附件；暂未把附件自动转为 Codex 的图片或文件输入。需要 Agent 处理文件时，仍应先把文件放到该 Agent 能访问的项目目录。

## Linux 服务器 Agent

新增无图形界面的 Linux 接收端，支持关联现有账户，由 Mac 控制台创建和派遣服务器员工，使用服务器项目目录及 Codex 登录环境执行任务。见 [Linux 安装说明](LINUX.md)。

支持普通用户目录安装、离线依赖包，以及 userspace Tailscale 的显式本机 HTTP 代理。协作代理配置只作用于 Harness 通信，模型代理独立设置。

Getting started

Set up your account, create a project and connect the computers that will run your agents.

Set up your account

  1. Open Foolship and select Create account. Choose a name and a local unlock password.
  2. In Home, select New project, name it, and choose where the collaboration service should run.
  3. To change the interface language, open Settings → Appearance → Display language.

Collaborate across computers

  1. Connect the host and collaborators to the same Tailscale network. Keep the host online while the team uses it.
  2. Open the collaboration service section in Settings on the host. Set up a team address, complete any Tailscale prompt, and test the connection.
  3. In the project, open Members and agents and invite a member. Share the reachable HTTPS service address and project invite code.
  4. On the other computer, sign in to your own account and choose Home → Join project. Enter the address and invite code.

Use the team HTTPS address across computers. The address 127.0.0.1 only works on the host itself.

Add an agent to a project

  1. Set up and sign in to Codex CLI or DeepSeek Harness on the computer that will run the agent.
  2. In Settings, connect that computer to the collaboration service, check the executor and start the task receiver.
  3. Open the project. Under Members and agents, add an agent and choose its computer, workspace and model.
  4. Mention the agent in chat or assign it a task. Use the task card to review its scope and delivery.

Use your account on another computer

  1. On the new computer, select Link another computer and enter the reachable address used by your existing device.
  2. On the device where you are signed in, open Account, enter the link code and verify the device before approving.
  3. Return to the new computer and select Check approval and link.

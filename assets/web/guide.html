Agent Harness 新手教程

从 Tailscale 组网开始，一步一步完成账户、团队入口、项目邀请和 Agent 接入。除安装与登录外，全程点击按钮，不需要终端。

先看懂 准备清单 1. Tailscale 2. 创建账户 3. 团队入口 4. 邀请入项目 5. 接入 Agent 第二台电脑 排查问题

先看懂：三个工具各做一件事

Tailscale · 让机器互通

把不同地点、不同 Wi-Fi 下的电脑放进一个安全的私有网络。

Agent Harness · 组织协作

管理个人身份、设备、项目、消息、Agent 和任务路由。

Codex CLI · 实际执行

在 Agent 所在的电脑上调用模型、读取项目目录并完成任务。

只有自己一台电脑？不需要 Tailscale

直接创建 Harness 账户、添加本机 Agent、创建本机项目即可。只有跨电脑或多人协作才需要下面的 Tailscale 流程。

群主

创建项目、选择管理员 Agent、生成项目邀请码并邀请成员。

服务托管者

提供一台保持在线的电脑，运行团队入口并保存项目成员、消息和任务记录。通常就是群主本人。

多人协作前准备清单

  • 群主和每位同事都已安装 Agent Harness。
  • 服务托管者准备一台可保持在线的 Windows 电脑。
  • 每个人都已安装 Tailscale，并有自己的登录身份。
  • 每台准备运行 Agent 的电脑都已安装并登录 Codex CLI；Harness 不会自动安装或登录 Codex。
  • 每个人创建自己的 Harness 账户；不要共享账户、解锁密码或设备关联码。

第 1 步：先让双方的 Tailscale 连通

1

群主发邀请

  1. 打开 Tailscale 管理台。
  2. 进入 Users → Invite external users。
  3. 输入同事使用的邮箱并发送邀请。
2

同事接受并登录

  1. 使用收到邀请的那个身份接受邀请。
  2. 打开电脑上的 Tailscale，用相同身份登录并确认已连接。
3

双方核对在线状态

群主在管理台的 Users 中确认用户已加入，在 Machines 中确认双方电脑在线；同事也在客户端确认自己的设备在线。

成功标志：群主能在 Machines 里看到同事的电脑。这里显示的 100.x.x.x 是机器地址，不是稍后要填写的团队服务地址。

第 2 步：每个人创建自己的 Harness 账户

  1. 群主和同事分别在自己的电脑打开 Harness。
  2. 点击 创建账户。
  3. 填写自己的账户名称和本机解锁密码。
  4. “连接设置”保持默认，点击 创建并进入。
成功标志：进入控制台，左下角显示自己的账户，并能看到“我的 Agents”和“我的项目”。

加入别人的项目不需要重新注册，也不应登录群主的账户。Harness 密码只用于本机解锁，与 Tailscale、Codex、OpenAI 或 GitHub 密码无关。

第 3 步：群主创建团队服务地址

  1. 在准备保持在线的托管电脑打开 设置 → 协作服务。
  2. 点击 创建团队入口。
  3. 如果显示“等待 Tailscale 确认授权”，点击 打开 Tailscale 授权页面，在浏览器中允许 Serve。
  4. 回到 Harness，等待“团队入口已就绪”。
  5. 点击 检测连接。
  6. 检测通过后点击 复制地址。
成功标志：应用显示形如 https://电脑名.xxxx.ts.net 的团队服务地址，并且“检测连接”通过。这才是应发给同事的地址。

Harness 可以通过按钮配置入口，但不会自动安装 Tailscale，也不会代替用户登录。托管电脑、Tailscale 和 Harness 服务需要保持运行。

第 4 步：创建项目并邀请同事

群主

  1. 在控制台点击 ＋ 新建项目。
  2. 填写名称，并选择自己的托管电脑作为协作服务。
  3. 点击 创建并进入。
  4. 在项目成员区域点击 邀请成员 → 生成邀请。
  5. 把 HTTPS 团队服务地址和“项目邀请代码”一起发给同事。

受邀同事

  1. 保持登录自己的 Harness 账户。
  2. 在控制台点击 凭邀请加入项目。
  3. 粘贴群主发来的 https://...ts.net 地址和项目邀请代码。
  4. 点击 加入。
成功标志：项目出现在同事的“我的项目”中；群主进入项目也能看到该成员。

项目邀请码 ≠ 设备关联码

项目邀请码让另一个人加入某个项目；设备关联码只用于同一个人的第二台电脑。群主不要把自己的设备关联码发给同事。

第 5 步：同事把自己的 Agent 接入项目

  1. 打开 设置 → 已加入的协作服务。
  2. 在群主服务旁点击 接入本机 agent → 确认接入。
  3. 在 设置 → 本机接收任务 点击 启动接收。
  4. 回到 控制台 → 我的 Agents → ＋ 添加员工。
  5. 选择自己的机器，设置员工名称、项目目录、Codex CLI、模型、思考强度和权限。
  6. 打开项目，点击 派遣我的员工。
成功标志：服务显示“本机已接入”，接收服务已启动，Agent 已启用并出现在项目成员中。

群主同样添加并派遣自己的 Agent，然后选择“管理员 Agent”。普通群聊默认由管理员 Agent 处理；要让非管理员回复，请在发送区使用“呼叫 Agent”选择它。

单独支线：同一个人的第二台电脑

新电脑 已经登录的电脑
登录页点击“关联我的另一台电脑” 点击左下角账户图标，进入“身份与关联设备”
填写已有账户使用的可达 HTTPS 地址和机器名，点击“获取新电脑关联码” 点击“输入新电脑的关联码”，输入新电脑显示的码
等待已有电脑批准 核对设备名称和指纹，依次点击“核对请求”“核对并批准”“批准关联”
点击“检查批准并完成关联” 确认两台电脑都出现在设备列表

关联码约 10 分钟有效。关联后共享账户、Agent 配置和项目列表；项目文件、Codex 登录和设备私钥不会自动同步。

常见错误，按这里排查

Tailscale 看不到同事的 machine

确认群主使用“Users → Invite external users”邀请；同事使用受邀身份接受并登录。双方客户端都应显示已连接，设备应在管理台 Machines 中在线。没有 machine 时先处理 Tailscale，不要继续创建入口。

出现 WinError 10061 或“目标计算机积极拒绝”

地址可以找到，但服务没有接收连接。检查托管电脑是否在线、Harness 是否运行、团队入口是否“已就绪”，然后重新点击“检测连接”。

地址是 127.0.0.1

它永远只代表当前电脑。单机使用可以；发给同事一定无效。应分享应用生成的 https://...ts.net 地址。

同事打不开团队服务页面

检查同事是否连入受邀的 Tailscale 网络、托管电脑是否在线、Serve 是否完成授权、地址是否完整包含 https://，以及托管电脑的“检测连接”是否通过。不要用 100.x.x.x 代替团队服务地址。

Agent 不回复
  1. 确认 Agent 所在电脑的 Codex CLI 已登录。
  2. 确认“已加入的协作服务”显示本机已接入。
  3. 确认已点击“启动接收”。
  4. 确认 Agent 已启用并派遣到当前项目。
  5. 普通群聊应有管理员 Agent；指定其他 Agent 时要用“呼叫 Agent”。
  6. 确认 Harness 代理设置符合这台电脑的网络环境。

也可以从 Codex 客户端使用协作

打开 设置 → 在 Codex 中使用协作，点击“连接到 Codex”。普通 Codex 对话随后可以在授权范围内读取 Harness 项目、发送消息和给自己的 Agent 派任务。
